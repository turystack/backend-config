# @turystack/backend-config

Shared biome + TypeScript config for turystack APIs and handlers.

## Installation

```bash
pnpm add -D @turystack/backend-config
```

## Presets

```json
{
  "extends": ["@turystack/backend-config/biome"]
}
```

Available: `@turystack/backend-config/biome`, `@turystack/backend-config/tsconfig.api`, `@turystack/backend-config/tsconfig.handler`
